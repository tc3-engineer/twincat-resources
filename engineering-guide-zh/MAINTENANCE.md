# 维护方法

1. 以 `data/catalog.json` 为资料源；新增条目必须说明来源、用途、版本、许可、核验日期和核验方式。
2. 改动前先重新打开原始页面；只有搜索摘要可用时标记 `search_result`，不能标记全文已核实。
3. 按域名和路径检查重复；对同一文档不同语言可保留确有必要的版本，并明确语言差异。
4. 固定源码更新时，先核验 changelog、README、LICENSE 与依赖，再移动对应 gitlink 并同步 `sources.lock.json`。不要只改 JSON 而不改子模块 SHA。
5. 本仓库不自动执行上游安装脚本、PLC 下载、激活或运行工程。构建与现场验证应留在独立测试环境。

本次没有创建定时任务，也没有承诺无人值守持续抓取。后续可沿当前目录结构继续补录、纠错或指定专题深化。
